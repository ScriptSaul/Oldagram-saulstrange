# Oldagram

A Scrimba project recreating an Instagram-style feed using HTML, CSS, and JavaScript.

## Versions

### Hardcoded Version
The original implementation, with each post written directly into the HTML.

### Automated Version
A refactored version that stores post data in JavaScript objects and dynamically renders the posts to the DOM.

## What I Practiced

- HTML structure and semantic elements
- CSS layout and styling
- JavaScript arrays and objects
- For loops
- Template literals
- DOM manipulation
- Dynamic rendering with innerHTML
